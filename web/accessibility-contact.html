Accessibility Statement

ORVIKA is committed to making its digital safety tools accessible.

Last reviewed: 17 November 2026 · Applies to the ORVIKA hosted web application

Accessibility commitment

ORVIKA is committed to making its hosted web application accessible. The publisher makes a WCAG 2.2 Level AA conformance claim for the complete web application, including responsive presentations.

Conformance claim

Guidelines: Web Content Accessibility Guidelines (WCAG) 2.2 — https://www.w3.org/TR/WCAG22/

Conformance level: Level AA.

Scope: The complete hosted ORVIKA web application at https://orvika-web.vercel.app/, including its responsive page presentations.

Technologies relied upon: HTML, CSS, JavaScript and Flutter Web.

Claim date: 17 November 2026.

Auditor: Er. Tapan Jatakia (C.Eng.), WCAG Auditor.

This is a conformance claim made by the publisher. W3C does not review, validate, certify or endorse this claim. The native Android application and third-party content outside the publisher’s control are excluded from this web conformance claim.

Platform coverage

This claim covers the hosted web application only. The native Android application is evaluated separately using applicable native accessibility guidance and assistive-technology testing; it is not included in this WCAG web conformance claim.

Accessibility feedback

To report an accessibility barrier, include the affected page or feature, what you attempted, the expected result, and concise reproduction steps. Browser and assistive-technology details are optional. Do not include passwords, one-time codes or unrelated sensitive information.
